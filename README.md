# ✦ QuickNotes

A small full-stack notes application built for a Git & GitHub workshop.

## 🚀 Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- API: REST API
- Styling: CSS

## ✨ Features

- Create notes
- View notes
- Search notes
- Delete notes
- Responsive UI
- Frontend connected to backend API
